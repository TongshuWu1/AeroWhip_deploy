## The goal

An accurate simulation of the coupled drone + cable, for sim-to-real-to-sim of a whip strike policy
(paper target RA-L, open-source release). The policy commands accelerations at 50 Hz through the
firmware flight pipeline. Task decisions approved 2026-10-28: `internal/agent_notes/aerowhip-task-decisions.md`.

## The fitting design (agreed)

`internal/fitting_and_adaptation_design.md`. Stages: 0 measurements (marker intervals from labels),
1 thrust map, 2 drone (drone-only flights), 3 cable + compact residual (measured clamp, 1 s
segments), 4 coupled validation (nothing fitted, per-flight bias cancelled, stroke test is the
yardstick), 5 randomisation, 6 freeze/train/fly. Each parameter is fitted only from the data that
sees it; coupled flights only validate. Decisions use held-out flights and results that reproduced
twice. No new bench measurements (user decision): CoM, inertia, arm, motor response stay nominal
and are randomised.

## Working rules (from the user; details in `internal/agent_notes/`)

- Approve scope before coding; update `internal/implementation_record.md` and `docs/` in the same
  change; never relax a criterion silently; preserve recordings and run artifacts.
- Full refits and training run through their windows (`python -m aerowhip.ui.fitting`,
  `python scripts/train.py`) so the user can watch; only short checks run silently.
- Commands for the user: one per block, never chained with `&&`.
- Never fly the drone yourself. No `ros2` CLI queries in the flight container unless the drone is
  landed and the user agrees (it stalled the 50 Hz loop and caused an emergency stop).
- Don't change Motive, the drone setup or the firmware; YAML/tuning changes only with the user's
  say-so. IMU alignment correction stays off (tested, no measurable effect). Don't change the cflib
  disconnect threshold.
- OptiTrack often misses some of the 10 cable markers: partial frames are valid, never force all 10.
- On a worker crash: rerun, trust only results that reproduced twice, don't change code because of it.
